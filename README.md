# Processamento de Linguagem Natural — PLN

Este repositório reúne projetos desenvolvidos com técnicas de **Processamento de Linguagem Natural (PLN/NLP)**, incluindo análise de sentimentos, métodos léxicos e modelos de linguagem baseados em Transformers.

Mais conteúdos e detalhes: https://samantads.com/

---

## Projetos

| Projeto | Técnica | Objetivo |
|---|---|---|
| [Análise de Sentimentos em Avaliações Hospitalares](https://github.com/samantaleke/analise-sentimentos-hospitais) | Análise de Sentimentos / Métodos Léxicos / DistilBERT | Comparação de métodos léxicos e modelos de linguagem na classificação de avaliações hospitalares como positivas, negativas ou neutras |
